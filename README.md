---

## 🎨 Visual Language & Design Architecture

- **Editorial Serif & Modern Sans**: Pairing `Instrument Serif` with `Plus Jakarta Sans` and `JetBrains Mono`.
- **Asymmetric Grid System**: Clean architectural borders (`rgba(255, 255, 255, 0.08)`), numbered section indexes (`01`, `02`, `03`...), and spacious layout.
- **Original Unmodified Portrait**: Framed inside an architectural portrait card with corner crosshair markers and live CGPA badge.
- **Dark / Light Mode**: Seamless theme switcher saving preferences to `localStorage` and detecting OS theme defaults.
- **Interactive Micro-animations**: Smooth entry reveals via `IntersectionObserver`, active navigation indicator (ScrollSpy), and validation feedback.

## 🎥 Video Customization

- Place your video file inside the `assets/` folder and name it `intro-video.mp4` (`assets/intro-video.mp4`).
- The player will automatically load and stream your video with full native playback controls (Play, Pause, Scrubbing, Volume, Fullscreen).

## 🚀 How to Run Locally

Open `index.html` directly in any web browser or use a lightweight local HTTP server:

```bash
# Using Python built-in server:
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.
